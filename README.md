# 🎴 Cardly - Profile Card Generator

A form-based web application that processes user inputs via POST requests and generates dynamic profile cards with PNG download functionality. Built with FastAPI and Vanilla JavaScript.

---

## ⚙️ How to Run Locally

1. **Install Dependencies:**
   ```bash
   pip install fastapi uvicorn pydantic
2. **Clone the repository**
3. **Run Application**
    ```bash
    python main.py
